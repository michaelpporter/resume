# Resume of Michael P. Porter

Authored in [Typst](https://typst.app). Check Releases for the latest PDF.

## Build locally

```sh
typst compile resume.typ resume.pdf
# live preview:
typst watch resume.typ
```

Pushing to `main` compiles `resume.typ` and publishes a GitHub Release
(`michaelpporter.pdf`) via `.github/workflows/publish.yaml`.
